# ترتيب بلس | Tarteeb Plus — Office Station

موقع مستقل لمعاينة مكتب **ترتيب بلس بأربع أرجل** وعرضه في الغرفة بالواقع المعزز، بواجهة عربية.

**[فتح التجربة / Live demo](https://lamamuidh.github.io/office-desk-ar/)**

## المزايا

- اختيار سطح بمقاس **180 × 80** أو **200 × 80 سم**.
- تدوير المجسّم وتكبيره في المتصفح.
- تجربة المكتب في الغرفة على الأجهزة والمتصفحات الداعمة للواقع المعزز.
- سطح بني داكن وقاعدة سوداء بأربع أرجل.
- ملفات مستقلة بالكامل، ولا تحتاج إلى مستودع آخر للتشغيل.

## الملفات

| الملف | وظيفته |
| --- | --- |
| `index.html` | واجهة الموقع العربية |
| `app.js` | اختيار المقاس وحالة التحميل وتشغيل الواقع المعزز |
| `style.css` | التنسيق المتجاوب |
| `model-viewer.min.js` | مكتبة عرض المجسمات، محفوظة مع المشروع |
| `desk-180.glb` | مجسّم مقاس 180 × 80 سم |
| `desk-200.glb` | مجسّم مقاس 200 × 80 سم |
| `generate-models.py` | مصدر توليد المجسمات |
| `.nojekyll` | نشر الملفات مباشرة عبر GitHub Pages |

## التشغيل المحلي

تحتاج إلى Python 3 فقط لتشغيل خادم محلي؛ لا توجد خطوة بناء أو حزم npm.

```bash
git clone https://github.com/LamaMuidh/office-desk-ar.git
cd office-desk-ar
python3 -m http.server 8000
```

افتح [http://localhost:8000](http://localhost:8000). لتجربة الواقع المعزز على الجوال، استخدم رابط الموقع المنشور عبر HTTPS وجهازًا مدعومًا.

## إعادة توليد المجسمات

```bash
python3 generate-models.py
```

يستخدم السكربت مكتبات Python القياسية فقط، ويعيد كتابة `desk-180.glb` و`desk-200.glb` في مجلد المشروع. عدّل أبعاد النموذج في السكربت ثم شغّله، وحدّث النصوص في الواجهة إذا تغيّرت المقاسات.

## النشر والتحديث

- الاستضافة عبر **GitHub Pages** من الفرع `main` والمجلد `/ (root)`.
- التعديلات المحفوظة في هذا الفرع تُنشر تلقائيًا؛ تابع حالة النشر من تبويب **Actions**.
- جميع مسارات الملفات نسبية لتعمل داخل مسار المستودع.
- أبقِ ملفات المجسمات ومكتبة العرض مع الصفحة عند نقل المشروع.

## تجربة الواقع المعزز

1. افتح رابط الموقع في Safari على آيفون أو Chrome على أندرويد مدعوم.
2. اختر المقاس واضغط «شوفه في غرفتك».
3. اسمح بالكاميرا إذا طُلب منك، ووجّهها إلى أرضية واضحة بإضاءة جيدة.
4. ارجع للصفحة لتبديل المقاس.

المعاينة ثلاثية الأبعاد تحتاج إلى WebGL. توفر الواقع المعزز يعتمد على الجهاز والمتصفح، وقد لا يعمل داخل المتصفحات المدمجة في التطبيقات.

## حدود النموذج

المجسّم تصوّر تقريبي مستوحى من صور المنتج، وليس ملف CAD مصنعيًا. مقاس السطح هو 180 × 80 أو 200 × 80 سم، وارتفاع المعاينة 75 سم وسماكة السطح في النموذج 2.5 سم. تفاصيل القاعدة وبقية الأجزاء تقريبية؛ راجع المواصفات الرسمية وقِس المساحة فعليًا قبل الشراء.

## English

Standalone Arabic AR preview for the **four-leg Tarteeb Plus desk**, with **180 × 80 cm** and **200 × 80 cm** desktop options.

Serve locally with `python3 -m http.server 8000`. Regenerate the GLB assets with `python3 generate-models.py`; no extra Python packages are required. GitHub Pages publishes from `main` at the repository root.

3D rendering requires WebGL. AR requires HTTPS and a compatible mobile device/browser. Models are approximate visual prototypes, not manufacturer CAD files.
