# Office Station — جرّب المكتب في غرفتك

موقع عربي لمعاينة المكتب ثلاثي الأبعاد وتجربته بالواقع المعزز، بمقاسي 180 × 80 و200 × 80 سم.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `style.css`: التنسيق.
- `app.js`: اختيار المقاس وتشغيل الواقع المعزز.
- `model-viewer.min.js`: مكتبة عرض المجسمات، محفوظة محليًا.
- `desk-180.glb` و`desk-200.glb`: المجسمات.
- `generate-models.py`: مصدر إنشاء المجسمات؛ يعمل باستخدام Python 3 دون حزم إضافية.

## التشغيل والتحديث
شغّل `python -m http.server 8000` وافتح `http://localhost:8000` للمعاينة المحلية. تجربة الواقع المعزز تحتاج HTTPS وجهازًا ومتصفحًا يدعمانها.

الاستضافة عبر GitHub Pages من الفرع `main` والمجلد `/ (root)`. أي تعديل محفوظ في هذا الفرع يعاد نشره تلقائيًا.

لتوليد المجسمات مجددًا: `python generate-models.py`.

المجسمات تقريبية لعرض الفكرة؛ قِس المساحة فعليًا قبل الشراء.

## مكتب ترتيب
الصفحة `tarteeb.html` تعرض ترتيب برجلين وسطح بني وقاعدة رمادية داكنة، بالمقاسين الواردين في صورة المنتج: 160 × 80 و180 × 80 سم. ارتفاع المعاينة 75 سم وسماكة النموذج 2.5 سم تقديريان للتجربة، وليسا مواصفات مصنعية مؤكدة. تفاصيل القاعدة تقريبية.

مصدر المجسمات: `generate-tarteeb-models.py`، ويُشغّل باستخدام Python 3 دون مكتبات إضافية. ملفات المجسمات: `tarteeb-160.glb` و`tarteeb-180.glb`.
